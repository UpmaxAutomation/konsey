# Plan 17-03: Hook Extraction & Component Reduction

**Phase**: 17 — Modular Refactor
**Goal**: Extract custom hooks from BoardView.jsx (573 LOC) and reduce ChatInterface.jsx (2,714 LOC) by extracting sub-components and hooks.

---

## Tasks

### 1. Extract BoardView hooks into `modules/canvas/hooks/`

| Hook | Source Lines | Purpose |
|------|-------------|---------|
| `useBoardState.js` | Board loading, saving, node/edge sync | Core board data management |
| `useCardActions.js` | Add/update/delete cards, AI card actions | Card CRUD operations |
| `useEdgeActions.js` | Connect/disconnect edges | Edge management |
| `useDebouncePosition.js` | Batched position saving | Performance optimization |
| `useKeyboardShortcuts.js` | Delete, Cmd+F, escape handlers | Keyboard input |

**Target**: BoardView.jsx reduced to ~200 LOC (render + hook composition)

### 2. Extract ChatInterface sub-components into `modules/chat/components/`

| Component | Source | Purpose |
|-----------|--------|---------|
| `MessageList.jsx` | Message rendering loop | Display messages |
| `MessageInput.jsx` | Textarea + file attach + voice | Input area |
| `ModelPicker.jsx` | Model selection dropdown | Model selection UI |
| `MessageActions.jsx` | Copy, edit, regenerate buttons | Per-message actions |

### 3. Extract ChatInterface hooks into `modules/chat/hooks/`

| Hook | State Variables | Purpose |
|------|----------------|---------|
| `useMessageSend.js` | input, streaming, abort | Message sending + streaming |
| `useModelSelection.js` | selectedModel, autoMode, favorites, recents | Model picking logic |
| `useFileAttach.js` | attachedFiles, isDragging, uploading | File attachment |
| `useVoiceInput.js` | isListening, transcript | Speech recognition |
| `useCompareMode.js` | compareModels, compareResponses, isComparing | Model comparison |

**Target**: ChatInterface.jsx reduced to ~800 LOC (render + hook composition)

### 4. Verify

- All extracted hooks work correctly
- No regressions in board or chat functionality
- `npm run build` passes
