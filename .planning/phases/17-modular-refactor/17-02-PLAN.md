## Tasks

### 1. Create module directories
- `frontend/src/modules/canvas/components/`
- `frontend/src/modules/canvas/styles/`
- `frontend/src/modules/chat/components/`
- `frontend/src/modules/chat/styles/`
- `frontend/src/shared/components/`
- `frontend/src/shared/styles/`

### 2. Move canvas components
Move 9 canvas components + their CSS files from `components/` to `modules/canvas/`.
Update all import paths in moved files.

### 3. Move chat components
Move 10 chat components + their CSS files from `components/` to `modules/chat/`.
Update all import paths in moved files.

### 4. Move shared components
Move 8 shared/utility components + CSS from `components/` to `shared/`.

### 5. Create barrel exports (index.js)
Each module gets an `index.js` that re-exports its public API.

### 6. Update import paths
Update all imports in:
- `App.jsx`
- `ProjectView.jsx`
- Any remaining component that imports moved files

### 7. Verify
- `npm run build` passes
- Dev server starts
- No broken imports

---

## Dependency Rules

- `modules/chat/` NEVER imports from `modules/canvas/`
- `modules/canvas/` NEVER imports from `modules/chat/`
- Both can import from `shared/` and `api/`
- `shared/` never imports from either module

## Success Criteria

- [ ] Module directories created
- [ ] All canvas components in modules/canvas/
- [ ] All chat components in modules/chat/
- [ ] Shared utilities in shared/
- [ ] Barrel exports working
- [ ] All imports updated
- [ ] `npm run build` passes
