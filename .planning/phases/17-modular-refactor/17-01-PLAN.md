# Plan 17-01: Backend Route Extraction

**Phase**: 17 — Modular Refactor
**Goal**: Extract all ~142 endpoints from `main.py` (7,539 LOC) into domain-specific route files under `backend/routes/`. Reduce main.py to ~200 LOC (app setup, middleware, router includes).

**Pattern**: Follow existing `routes/auth.py` and `routes/boards.py` — each file gets its own `APIRouter`, Pydantic schemas, and logger.

---

### 2. Move Pydantic schemas into their route files

Each route file contains its own request/response models. No shared schemas file needed — schemas are colocated with routes.

### 3. Slim main.py to ~200 LOC

After extraction, main.py contains ONLY:
- Imports + lifespan()
- `app = FastAPI(...)` creation
- Middleware (CORS, GZip, rate limiting, logging)
- `app.include_router(...)` for all routers
- Global exception handler
- Health endpoints (`/`, `/health`, `/api/debug/cors`)
- `get_all_models()` helper

### 4. Update `routes/__init__.py`

Export all routers.

### 5. Verify

- Backend starts without errors
- No circular imports
- All endpoints respond
