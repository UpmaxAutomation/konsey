**Scoring Formula:**
```python
def score_file_relevance(filename: str, content: str, query: str) -> float:
    query_words = extract_keywords(query)  # lowercase, remove stopwords
    content_lower = content.lower()

    score = 0.0
    for word in query_words:
        # Count occurrences in content
        score += content_lower.count(word)
        # Bonus for filename match
        if word in filename.lower():
            score += 10

    # Normalize by content length to avoid bias toward long files
    score = score / max(len(content) / 1000, 1)
    return score
```
